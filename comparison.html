비교 정리
① Original
장점: 0 byte (이미 있음), 모든 OS 지원.
단점: vendor마다 렌더 다름 (Apple 🟢 vs Google 🟢 vs Win 🟢 → 색·크기 다 다름). 시스템 폰트 사이즈 강제.
② Lucide
장점: 모든 환경 동일 렌더, CSS color 상속, 24px stroke 일관성, 인라인 SVG (외부 의존 0). shadcn·Vercel·Linear 표준.
단점: line icon이라 색만으로는 emoji보다 약간 덜 눈에 띔 (다만 배지 배경색이 강조해줌).
③ Fluent Emoji
장점: 가장 premium·modern 느낌, 3D 그라데이션, "이게 디자이너가 만든 디자인이다" 느낌 강함.
단점: jsdelivr CDN 의존 (오프라인 X), 인쇄 시 PNG 깨짐 가능, 제출 환경에 따라 차단 가능.

본 과제 컨텍스트 추천: ② Lucide — 단일 HTML 자체완결성 + 디자인 일관성. ③ Fluent는 시각 쇼크는 크지만 외부 CDN 의존이라 평가자 환경에서 가끔 막힘. ①은 디바이스마다 달라보여 "디자인이 안 정렬됨"으로 보일 위험.
